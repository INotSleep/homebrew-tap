# Homebrew tap of INotSleep

```bash
brew install --cask inotsleep/tap/detour
```

[Detour](https://github.com/INotSleep/Detour): an open-source SSH client with end-to-end encrypted sync and teams. The cask installs `Detour.app` and puts the `detour` command line on your `PATH`. Detour updates itself; `brew upgrade` works too.
